Configure AI analysis

A platform administrator can enable an approved AI provider through the OpsCart deployment configuration. Credentials stay in an existing Kubernetes Secret.

  1. Create or select a Secret containing the provider API key.
  2. Set ai.enabled, ai.provider, ai.baseURL, ai.model, ai.existingSecret, and ai.apiKeyKey in Helm values.
  3. Upgrade the release and wait for the dashboard rollout to complete.
